# HabitLoop

HabitLoop is a light-theme, local-first Android habit and personal-growth application built with Kotlin and Jetpack Compose. It combines flexible routines, meaningful insights, private social circles, cooperative Community Jams, adaptive mental-skill exercises, and an ethical reward economy.

## Product principles

- Progress over popularity: no public follower counts or exposed habit histories.
- Local-first reliability: habits and check-ins work offline with optional Firebase backup.
- Fair motivation: weekly consistency is more important than lifetime streak age.
- Explicit privacy: Jam contact handles are optional, off by default, and visible only to fellow participants.
- Ethical rewards: fixed-price cosmetic unlocks and a free daily reward; no paid loot boxes or purchasable leaderboard advantages.

## Features

- 21 habit templates plus custom habits
- Custom weekday scheduling and schedule-aware streaks
- Calendar history, completion patterns and responsive charts
- Confirmed daily check-ins and Loop Coin rewards
- Streak protection through coins or optional rewarded ads
- Loop Store with persistent cosmetic profile titles
- Google, phone and verified email/password authentication
- Firebase cloud backup and multi-device account recovery
- User-created circles, members, check-ins, discussions and reporting
- Seven-day consistency leaderboards
- Community Jams with optional Instagram/Discord handles
- Adaptive memory, attention, perspective and reflection exercises
- On-device wellness-only breath-motion estimation
- Theme soundscape with Settings control
- Daily reminders, notification categories and quiet hours
- Gentle, playful and direct reminder tones without sensitive demographic profiling
- Firebase Cloud Messaging client and circle-message Cloud Function
- Android home-screen widget

## Local setup

1. Install Android Studio with JDK 17 and Android SDK 34.
2. Add the Firebase Android configuration at `app/google-services.json`.
3. Add `local.properties` with your Android SDK path.
4. Build:

   ```powershell
   .\gradlew.bat testDebugUnitTest assembleDebug
   ```

The debug APK is generated at `app/build/outputs/apk/debug/app-debug.apk`.

## Firebase setup

Enable these Authentication providers:

- Google
- Phone
- Email/password

Register both SHA-1 and SHA-256 certificates for the Android app. Deploy Firestore rules:

```powershell
firebase deploy --only firestore:rules --project habitloop-e20e6
```

Install and validate notification functions:

```powershell
cd functions
npm install
npm run lint
```

Deploy circle-message push notifications:

```powershell
firebase deploy --only functions:notifyCircleMessage --project habitloop-e20e6
```

Cloud Functions deployment requires the Firebase Blaze plan. The Android client, token registration, notification channels and local reminders work without deploying the function; server-generated circle pushes begin after it is deployed.

## Notification behavior

- Android 13+ notification permission is requested in context.
- Daily incomplete-habit reminders are scheduled locally.
- Circle messages use FCM data messages generated by the Firestore trigger.
- Open circle discussions update instantly through Firestore snapshot listeners.
- On the free Firebase plan, WorkManager checks for new joined-circle messages approximately every 15 minutes.
- True closed-app instant push requires deployment of the included Cloud Function on Firebase Blaze.
- Users can disable circle, Jam and streak notifications independently.
- Quiet hours suppress non-urgent notifications between 10 PM and 7 AM.
- Message push previews contain only the chosen username, circle title and shortened message.

## Security and privacy

- Firestore rules gate circle discussions to members.
- Contact information and private habits are never placed in public circle data.
- Moderation reports are write-only for clients.
- Device FCM tokens are stored inside the authenticated user's private `devices` collection.
- Never commit service-account credentials, signing keys, `.env` files or `local.properties`.
- `google-services.json` is intentionally excluded; each contributor supplies their own Firebase client configuration.
